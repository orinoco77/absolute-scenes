# Privacy Statement for Absolute Scenes

**Effective Date:** September 25, 2025
**Application:** Absolute Scenes - Professional Book Writing Software
**Developer:** Adam Short (ajs@shiny.org.uk)

## Overview

Absolute Scenes is designed with privacy as a core principle. We believe your creative work should remain private and under your complete control. This privacy statement explains how we handle your information when you use our application.

## What Information We Collect

### Information You Provide
- **Author Name**: Your name as entered for book authorship and collaboration features
- **Book Content**: All manuscripts, characters, locations, and notes you create
- **Application Settings**: Your preferences for themes, fonts, and application behavior

### Information We Do NOT Collect
- **Personal Information**: No email addresses, phone numbers, or physical addresses required
- **Usage Analytics**: We do not track how you use the application
- **Behavioral Data**: No monitoring of your writing habits or patterns
- **Marketing Data**: No advertising identifiers or marketing profiles
- **Crash Reports**: No automatic error reporting or telemetry

## How We Store Your Information

### Local Storage (Primary)
- **All book files** are stored locally on your device in `.book` format
- **Application settings** are stored locally using standard operating system preferences
- **Complete offline functionality** - no internet connection required for core features

### Optional Cloud Storage
- **GitHub Integration**: Optionally back up your work to your own private GitHub repositories
- **User-Controlled**: You must explicitly enable and configure GitHub backup
- **Your Repositories**: Data is stored in repositories you own and control
- **Revocable Access**: You can disconnect GitHub integration at any time

## Third-Party Services

### GitHub (Optional)
**Purpose**: Backup and version control for your manuscripts
**Data Shared**: Book content and metadata when you choose to sync
**Your Control**: Completely optional - enable only if you want cloud backup
**Authentication**: Uses your personal GitHub access token
**Privacy**: Data stored in your private GitHub repositories under your control

### Google Fonts (Browser Version Only)
**Purpose**: Loading typography fonts for document formatting
**Data Shared**: Standard web font requests (no personal information)
**Alternative**: Desktop version uses local fonts only

### No Other Services
- No analytics services (Google Analytics, etc.)
- No advertising networks or trackers
- No social media integrations beyond optional GitHub
- No automatic update checking with personal data

## Your Rights and Controls

### Complete Data Control
- **Local-First Design**: All data stored locally by default
- **Export Options**: Export your work to PDF, HTML, EPUB, or JSON formats
- **No Lock-In**: All data in open, portable formats
- **Manual Sync**: You control when and if data is backed up to GitHub

### GitHub Integration Controls
- **Opt-In Only**: GitHub features are completely optional
- **Repository Selection**: Choose which repository to use for backup
- **Sync Control**: Manual sync - no automatic uploads
- **Disconnect Anytime**: Remove GitHub integration while keeping local data
- **Token Management**: Revoke access tokens directly in GitHub settings

### Settings Management
- **Preference Control**: All application settings can be reset or modified
- **Theme Settings**: Stored locally, no external sharing
- **Font Preferences**: Handled locally with optional web font loading

## Data Security

### Local Security
- **OS-Level Protection**: Files protected by your operating system's security
- **Standard Storage**: Uses secure application data directories
- **No Additional Encryption**: Files are as secure as your device's file system

### Token Security
- **Secure Storage**: GitHub tokens stored using browser/OS encryption systems
- **No Transmission**: Tokens only sent to GitHub's official API endpoints
- **User-Managed**: You generate and can revoke tokens in your GitHub account

## Data Retention

### Local Data
- **Indefinite Storage**: Data persists until you manually delete it
- **User Control**: You decide when to delete books, characters, or settings
- **No Automatic Cleanup**: We never automatically delete your creative work

### GitHub Data
- **Your Repository**: Data stored according to GitHub's terms and policies
- **User Control**: Delete repositories or files anytime through GitHub
- **Independent Storage**: We don't control or access your GitHub data

## Children's Privacy

Absolute Scenes does not specifically target children under 13. We do not knowingly collect personal information from children. The application can be used by children with parental supervision, but no personal information beyond book content is collected.

## International Users

Absolute Scenes works entirely locally by default. If you choose to use GitHub integration:
- Data may be transferred to GitHub's servers (various global locations)
- GitHub's privacy policy and data handling practices apply
- You control which country/region your GitHub repositories are located in

## Changes to This Privacy Statement

We may update this privacy statement to reflect changes in the application or legal requirements. Updates will be posted with the application and on our GitHub repository. Continued use of the application after changes constitutes acceptance of the updated privacy statement.

# Microsoft Store Privacy Statement - Absolute Scenes

## Privacy Statement Summary

**Absolute Scenes** is a privacy-focused writing application that stores your data locally by default. We do not collect personal information, usage analytics, or share your data with third parties.

## Data We Collect

**Local Data Only:**
- Book manuscripts and notes you create
- Application preferences (themes, fonts)
- No personal information required

**We DO NOT collect:**
- Email addresses or contact information
- Usage analytics or tracking data
- Location information
- Advertising identifiers
- Crash reports or telemetry

## Data Storage

**Primary Storage:** All data stored locally on your device
**Optional Cloud Backup:** Users may optionally connect their own GitHub account for backup
**No Default Cloud Storage:** Application works completely offline

## Third-Party Services

**GitHub (Optional Only):**
- Purpose: Optional backup to user's private repositories
- Data Shared: Only book content when user chooses to sync
- User Control: Completely optional, user-initiated only
- Authentication: User's own GitHub account and tokens

**Google Fonts (Browser Version):**
- Purpose: Loading fonts for document typography
- Data Shared: Standard font requests only, no personal data

**No Other Third Parties:**
- No analytics services
- No advertising networks
- No crash reporting services
- No social media integrations

## User Rights

- **Complete Local Control:** All data stored on your device
- **Optional Cloud Features:** GitHub integration is opt-in only
- **Data Export:** Export work to PDF, HTML, EPUB, or JSON
- **No Lock-in:** Open file formats, easy to switch applications
- **Disconnect Anytime:** Remove cloud features while keeping local data

## Children's Privacy

Application does not target children under 13 and does not collect personal information from any users.

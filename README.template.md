## ✨ What Makes It Special

Absolute Scenes transforms how you write books by organizing your story into manageable scenes rather than overwhelming chapters. Whether you're writing solo or collaborating with others, this application provides the structure and tools you need to bring your story to life.

### 🎯 Core Features

- **📝 Scene-Based Writing** - Break your story into focused, manageable pieces
- **👥 Real Collaboration** - Multiple authors can work on the same book simultaneously  
- **🔄 Smart Sync** - GitHub integration with intelligent conflict resolution
- **💾 Never Lose Work** - Automatic backups with full recovery capabilities
- **📊 Track Progress** - Visual progress tracking and word count goals
- **🎨 Rich Formatting** - Support for markdown with live preview

### 🚀 Collaboration Features

- **Scene Assignment** - Assign specific scenes to different authors
- **GitHub-Driven Workflow** - All collaboration happens through GitHub repositories
- **Conflict-Free Editing** - Smart sync prevents authors from overwriting each other
- **Testing Mode** - Try collaboration features even in single-author repos

## 🎬 Quick Start

```bash
# Clone and setup
git clone https://github.com/yourusername/absolute-scenes.git
cd absolute-scenes
npm install

# Launch the application
npm start
```

Your book will open in your default browser at `http://localhost:3000`

## 💡 How to Use

1. **Start Writing** - Create scenes and organize them into chapters
2. **Add Characters** - Build detailed character profiles and track relationships  
3. **Set Goals** - Define word count targets and deadlines
4. **Collaborate** - Connect to GitHub to work with co-authors
5. **Export** - Generate professional manuscripts in various formats
